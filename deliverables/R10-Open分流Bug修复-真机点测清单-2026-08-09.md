# R10「Open 分流 Bug 修复」真机点测清单

> QA：严过关　|　日期：2026-08-09　|　插件版本：manifest 0.1.9（未 commit）
> 产物：`dist-extension/`（content-md.js 13,122 B / background.js 3,377 B）
>
> **本清单只包含机器替代不了的项**：需要真实 Chrome 权限开关、真实原生文件选择器、
> 真实新标签页导航。门禁、类型检查、48 条行为断言我已在本地跑完并全绿。

---

## 0. 装载准备（每次改完产物都要做）

1. 打开 `chrome://extensions`，右上角开启「开发者模式」。
2. 若已装过 MDnote：先点该卡片上的 **刷新（↻）**；没装过则「加载已解压的扩展程序」→ 选
   `/Users/bot/Documents/MDnote/dist-extension`。
3. 准备两个测试文件（放同一目录，便于目录列表里互相看得见）：
   - `~/Desktop/mdnote-test/A.md` —— 内容随便写几行，**当前页**用它
   - `~/Desktop/mdnote-test/B.md` —— 内容写一行显眼的 `# 我是 B 文件`
4. **关键**：每切换一次「允许访问文件网址」开关，Chrome 都会重载扩展，
   **必须把已打开的 .md 页签全部关掉重开**，否则测的是旧 content script。

---

## ① 关开关 → 有内容页 Open（**R10 核心验收项**）

**目的**：验证「点 Open 选完文件啥都没发生」已被消灭。

| 步骤 | 操作 |
|---|---|
| 1 | `chrome://extensions` → MDnote → **详细信息** → 把「允许访问文件网址」**关掉** |
| 2 | 关掉所有 .md 页签，重新在 Chrome 里打开 `A.md`（拖进去或 `Cmd+O`） |
| 3 | 确认 MDnote 内联编辑器正常渲染出 A 的内容（不是纯文本） |
| 4 | 点工具栏 **Open** |
| 5 | 在弹出的原生选择器里选 **B.md** |

**预期（三条都要满足，缺一即失败）**
- [ ] **当前页**编辑器内容变成 B 的内容（`# 我是 B 文件`）——不是空白、不是仍停在 A
- [ ] 出现**黄色 warning toast**，文案为：
      `新标签页目录打开失败（MDnote 需勾选「允许访问文件网址」），已改为在当前页打开选中文件`
- [ ] **没有**新标签页弹出；地址栏仍是 `A.md` 的 file:// 地址（这是降级的正常表现）

**失败判据（出现任一即打回）**
- 什么都没发生（旧 R10 bug 复现）
- 只弹红色 error toast、内容没加载
- 内容加载了但没有黄色 toast（用户不知道为什么落点不对）

## ② 开开关 → 有内容页 Open（正常分流路径）

**目的**：确认「修复静默失败」没有把正常路径一起判死（我最担心的过度修复方向）。

| 步骤 | 操作 |
|---|---|
| 1 | `chrome://extensions` → MDnote → 把「允许访问文件网址」**打开** |
| 2 | 关掉所有 .md 页签，重新打开 `A.md` |
| 3 | 在编辑器里**随手多敲几个字**（制造未保存修改，用于验证当前页不被动） |
| 4 | 点 **Open** → 选 **B.md** |

**预期**
- [ ] **新开一个标签页**，展示 `mdnote-test/` 目录的 file:// 文件列表
- [ ] **当前页一字未动**：仍是 A 的内容 + 你刚敲的那几个字都还在
- [ ] 当前页**没有**任何 toast（尤其不能有黄色降级提示）
- [ ] 在新标签页的目录列表里点 `B.md` → 该页变成 MDnote **内联编辑器**并渲染 B 的内容

**失败判据**
- 没开新标签页却弹了黄色降级 toast（说明 `isAllowedFileSchemeAccess` 判据失灵，误伤已勾选用户）
- 当前页内容被 B 覆盖 / 未保存修改丢失

## ③ 空文档 Open（既有行为不得回归）

| 步骤 | 操作 |

| 2 | 点扩展图标（或 `Cmd+Shift+M`）开一个**空白**编辑器标签页 |
| 3 | 不输入任何内容（全空白/只有空格换行也算空） |
| 4 | 点 **Open** → 选 `B.md` |

**预期**
- [ ] **就地**加载 B 的内容进当前编辑器
- [ ] **没有**黄色 warn toast
- [ ] **没有**新标签页

## ④ 降级后按 Save（句柄复用验证）

**前置**：先完整做完 ①（关开关降级，当前页已显示 B 的内容）。

| 步骤 | 操作 |
|---|---|
| 1 | 在当前页编辑器里修改 B 的内容，例如加一行 `R10 降级保存测试` |
| 2 | 按 `Cmd+S`（或点 Save） |
| 3 | Chrome 弹出原生「**允许编辑**」提示 → 点允许 |
| 4 | 用访达/终端打开 `~/Desktop/mdnote-test/B.md` 查看 |

**预期**
- [ ] 原生「允许编辑」提示**只弹一次**（本会话后续 Save 静默）
- [ ] **没有**弹出「另存为」对话框（句柄已缓存，不该再选一次文件）
- [ ] `B.md` 磁盘内容确实包含你新加的那行
- [ ] **A.md 内容未被改动**（关键：别把 B 的内容写回 A）
- [ ] 再改一次内容按 `Cmd+S` → 完全静默保存成功

## ⑤ 既有能力不退化（回归抽查）

### ⑤-a RACE-01：自动保存 vs 显式 Save 并发
- [ ] 打开 `A.md`，快速连续敲字（触发 3s 防抖自动保存），**在自动保存正要发生的瞬间**按 `Cmd+S`
- [ ] 预期：显示保存成功，**不**出现「保存失败 / 已取消」的错误提示
- [ ] 磁盘上 `A.md` 内容与编辑器一致

### ⑤-b R7 冷启动 Save
- [ ] **新开**一个 `A.md` 页签，**不点 Open**，直接改内容后按 `Cmd+S`
- [ ] 预期：弹**一次「另存为」**对话框（不是「打开文件」对话框），且
      文件名已预填 `A.md`、起始目录落在 A 所在目录附近（Desktop/Documents 等）
- [ ] 确认后写回原文件；同会话再次 `Cmd+S` **零弹窗**

### ⑤-c R8 Open 无中间遮罩
- [ ] 点 Open 后**直接**弹出系统原生文件选择器
- [ ] **不得**先出现一层半透明黑色「Click to open」遮罩

### ⑤-d Open 取消
- [ ] 点 Open → 在原生对话框按 **Esc / 取消**
- [ ] 预期：安静返回，编辑器内容不变，**不**弹任何 error / warn toast

## ⑥ 补充排查项（QA 发现的窄口风险，建议一并试）

**慢速选择场景** —— 我在代码审读中发现编辑器侧桥接有 **60 秒**结果超时
（`src/lib/platform.ts:148 BRIDGE_RESULT_TIMEOUT_MS`），而原生文件选择器是用户自定节奏的。

| 步骤 | 操作 |
|---|---|
| 1 | 开关**关掉**（走 ① 的降级路径），打开有内容的 `A.md` |
| 2 | 点 **Open**，在原生对话框里**故意磨蹭超过 70 秒**（到处翻目录），然后才选 `B.md` |
| 3 | 观察当前页；随后按 `Cmd+S`，再去磁盘看 `B.md` |

**预期（若实现正确）**：与 ① 一致——加载 B 内容 + 黄色 toast。

**若出现下列任一，请务必记录并反馈（属于我判定的待修风险）**
- [ ] 选完文件后**啥都没发生**（超时把结果吞了）
- [ ] ⚠️ 更严重：页面仍显示 A 的内容，但按 `Cmd+S` 后 **`B.md` 被 A 的内容覆盖**
      （父页面已缓存 B 的句柄、编辑器却没收到 B 的内容）

> 这一项**不阻断 R10 交付**（触发需 >60 秒选择），但一旦复现请直接反馈，
> 我已把修复建议给到工程师（把 60s 上调至 5 分钟对齐 Save 的交互超时，
> 或改为父页面收到编辑器确认后再缓存句柄）。
