| 约定 | 说明 |

## §1 Mermaid 容器 + Diagram ⟷ Source 切换（R1.3）

### 1.1 视觉形态

- 每个 ```` ```mermaid ```` 块渲染为一个**带细边框的容器**，内部自上而下：`[切换控制条] → [图 / 源码]`。
- 控制条放在容器**顶部右对齐**（不是浮在图上的浮层），这样 Source 态下与复制按钮不会互相压盖，也便于 QA 肉眼确认。
- **控制条常驻可见**（区别于复制按钮的 hover 出现）：切换是核心能力，藏在 hover 后面会被用户当成没有。
- 容器承载原 `<pre>` 上的 `data-source-line`，行号照常显示（见 §4）。

### 1.2 尺寸 / 间距 / 圆角 / 字号

| 元素 | 规格 |
|---|---|
| 容器 `.preview-mermaid` | `position: relative; margin: 0 0 1em; padding: 12px; border: 1px solid var(--mf-border); border-radius: 8px; background: var(--mf-bg-primary);` |
| 控制条 `.preview-mermaid-toolbar` | `display: flex; justify-content: flex-end; margin: 0 0 8px;`（无自身背景） |
| 分段轨道 `.preview-seg` | `display: inline-flex; gap: 2px; padding: 2px; background: var(--mf-bg-tertiary); border-radius: 6px;`（同 `.view-toggle-group` 观感，缩小版） |
| 分段按钮 `.preview-seg-btn` | `height: 22px; padding: 0 8px; border: none; border-radius: 4px; font-size: 11.5px; font-weight: 500; background: transparent; color: var(--mf-text-muted);` |
| 图区 `.preview-mermaid-canvas` | `display: flex; justify-content: center; overflow-x: auto;` |
| 图内 SVG | `max-width: 100%; height: auto; display: block;`（**不设固定宽**，宽度自适应；高度按比例） |
| 图内文字 | 字体族随预览设置（mermaid 初始化时把 `--preview-font-family` 传给 `themeVariables.fontFamily`）；字号用 mermaid 默认，**不覆盖**，只保证 `max-width:100%` 后整体缩放不溢出 |

### 1.3 交互态（切换按钮）

| 态 | 背景 | 字色 |
|---|---|---|
| default（未选中） | transparent | `--mf-text-muted` |
| hover | `--mf-bg-hover` | `--mf-text-primary` |
| active（选中，`.is-active`） | `--mf-bg-primary` + `box-shadow: var(--mf-shadow-sm)` | `--mf-accent` |
| focus-visible | §0.2 焦点环 | — |

### 1.3.1 容器级点击行为（与主理人裁决 Q1 一致，详见 §3.1.1）

| 点击位置 | 行为 | 光标 |
|---|---|---|
| 图本体（SVG 及其留白） | 打开放大浮层 | `zoom-in` |
| 容器留白 / 图外区域 | 按 R2 跳编辑器源行 + 600ms 闪烁 | `default` |
| 控制条、复制按钮 | 自身动作，`stopPropagation` | `pointer` |

### 1.4 空态 / 异常态

| 场景 | 表现 |
|---|---|
| 空 mermaid 块（```` ```mermaid ```` 后无内容） | 按 §2 的**语法错误**路径处理（源码块 + 提示条），不渲染空框 |
| Source 态 | 图区替换为代码块（复用 `.preview-pane pre` + hljs 现有样式，见 §3 DOM 契约），容器边框与控制条保持不变 |
| 开关关闭（`Preview > Mermaid Diagrams` 关） | **不生成容器与控制条**，该块就是普通代码块（含复制按钮） |

### 1.5 响应式 / 溢出

- 窄预览区：SVG `max-width:100%` 后由浏览器按 viewBox 等比缩放，**不出现横向滚动条**；极端窄（< 280px）允许图区自身 `overflow-x: auto`（图区滚动，不是整页滚动）。
- 切换状态**逐块独立**（每块各自 state），不受其他块影响，也不受滚动/重渲染影响。

## §2 Mermaid 失败提示条（R1.5）

### 2.1 视觉形态

块**上方**（容器边框内、控制条之下、源码块之上）一条左色条提示：图标 + 标题 + 原始 message。三种场景共用同一组件，用颜色分级。

### 2.2 尺寸 / 间距 / 圆角 / 字号

| 元素 | 规格 |
|---|---|
| 容器 `.preview-alert` | `display: flex; align-items: flex-start; gap: 8px; padding: 8px 12px; margin: 0 0 8px; background: var(--mf-bg-secondary); border-left: 3px solid …; border-radius: 0 6px 6px 0;` |
| 图标 `.preview-alert-icon` | 文本 `⚠`，`font-size: 13px; line-height: 1.5;` 字色随级别 |
| 标题 `.preview-alert-title` | `font-size: 12.5px; font-weight: 600; color: var(--mf-text-primary);` |
| message `.preview-alert-msg` | `display: block; font-size: 12px; color: var(--mf-text-secondary); white-space: pre-wrap; overflow-wrap: anywhere; margin-top: 2px;` |
| 级别色 | 语法错误 → `border-left-color: var(--mf-error)`，图标 `var(--mf-error)`；**图类型未启用** → `var(--mf-warning)`；**渲染器加载失败** → `var(--mf-warning)` |

### 2.3 交互态

- **纯展示，不可点、不可关**（随下次渲染消失）。`role="status"`（非阻塞）。
- 不进 hover 态，不抢焦点，`user-select: text`（允许用户复制报错信息去排查）。
- 鼠标悬停时把完整 message 放进 `title` 属性（长文本被折行时仍可看全）。

### 2.4 空态 / 异常态

| 场景 | 表现 |
|---|---|
| message 为空 / mermaid 未给出 message | 只显示标题，不显示空行 |
| message 超长（多行堆栈） | 原样 `pre-wrap` 展示，不截断、不省略号（排查需要；出现频率低） |
| 整块渲染失败但非 mermaid 错（如 sanitize 抛错） | 兜底：显示源码块，**不显示提示条**，不阻塞其余预览（与 PRD §1.5「不阻塞预览其余内容」一致） |

### 2.5 响应式 / 溢出

- 容器宽度 = 父容器内容宽；`overflow-wrap: anywhere` 保证超长 token（如含 URL 的报错）不撑破预览区。
- 不产生横向滚动条。

## §3 图放大浮层 + Download SVG（R1.7 / C2）

### 3.1 视觉形态

最简自研 overlay：全屏半透明遮罩 + 居中面板。面板自上而下：`✕ 关闭（右上）` / `图（自适应居中，可滚动）` / `操作区（右下：Go to source · Download SVG）`。

#### 3.1.1 点击热区归属（主理人裁决 Q1，已锁定）

| 点击位置 | 行为 |
|---|---|
| **图本体**（`.preview-mermaid-canvas` 内的 SVG，含其留白） | 打开**放大浮层**；`cursor: zoom-in`。**不触发** R2 跳转 |
| **Mermaid 容器的留白 / 图外区域**（容器 padding、控制条空白、图与边框之间的空隙） | 按 **R2** 跳转编辑器对应源行（取该容器 `data-source-line`），600ms 闪烁；`cursor: default` |
| **控制条（Diagram/Source）**、**复制按钮** | 只执行自身动作，`stopPropagation`，**不冒泡**到容器与浮层 |
| **Source 态的代码块** | 按 R2 跳转（普通预览元素行为，与现状一致） |
| 浮层内 `Go to source` | 关闭浮层 → 按 R2 跳转该块源行 + 600ms 闪烁（独占预览模式下走 D5 pending 机制） |

### 3.2 尺寸 / 间距 / 圆角 / 字号

| 元素 | 规格 |
|---|---|
| 遮罩 `.preview-lightbox` | `position: fixed; inset: 0; background: rgba(0,0,0,.55)`（暗色主题 `rgba(0,0,0,.7)`）；`z-index: 9998`（**低于 toast 的 9999**，保证 toast 仍可见）；`display:flex; align-items:center; justify-content:center; padding: 24px;` |
| 面板 `.preview-lightbox-panel` | `position: relative; display: flex; flex-direction: column; gap: 12px; width: min(92vw, 1100px); max-height: 88vh; padding: 16px; background: var(--mf-bg-primary); border: 1px solid var(--mf-border); border-radius: 12px; box-shadow: var(--mf-shadow-lg);` |
| 关闭 ✕ `.preview-lightbox-close` | 同 `.about-close` 观感：`position:absolute; top:10px; right:12px; width:28px; height:28px; border:none; background:none; border-radius:6px; color:var(--mf-text-muted); font-size:16px;` |
| 图区 `.preview-lightbox-canvas` | `flex: 1; min-height: 120px; display: flex; align-items: center; justify-content: center; overflow: auto;` |
| 图区 SVG | `max-width: 100%; max-height: 100%; width: auto; height: auto;`（放大靠面板比预览区更宽实现；**不强制拉伸超过面板**） |
| 操作区 `.preview-lightbox-actions` | `display: flex; justify-content: flex-end; gap: 8px;`（组内从左到右：`Go to source` → `Download SVG`，主按钮在最右） |
| 主按钮 `Download SVG` | `height: 32px; padding: 0 16px; border: 1px solid var(--mf-accent); border-radius: 6px; background: var(--mf-accent); color: #fff; font-size: 13px; font-weight: 500;`（同 `.settings-btn-primary`） |
| 次按钮 `Go to source` | `height: 32px; padding: 0 16px; border: 1px solid var(--mf-border); border-radius: 6px; background: var(--mf-bg-primary); color: var(--mf-text-secondary); font-size: 13px;`（同 `.settings-btn-secondary`）；hover → 背景 `--mf-bg-hover` + 边框 `--mf-accent`；focus-visible → §0.2 焦点环。文案 `Go to source`，**不带图标**（保持与 `Download SVG` 的 ⬇ 之外的视觉平衡，避免三个按钮都是图标按钮） |
| 图本体热区 | `.preview-mermaid-canvas { cursor: zoom-in; }`（只在 Diagram 态；Source 态为普通代码块光标） |

### 3.3 交互态与关闭行为

| 交互 | 行为 |
|---|---|
| 打开 | 面板 `animation: 0.15s ease` 淡入（复用 `aboutFadeIn` 的写法）；打开瞬间焦点落在**关闭按钮**上 |
| ESC | 关闭（document 级 keydown，与 SettingsDialog 一致） |
| 点击遮罩 | 关闭；**点击面板内部不关闭**（`stopPropagation`） |
| 点击 `✕` | 关闭 |
| `Go to source` | **先关闭浮层**，再按 R2 跳到该块的源行并闪烁 600ms；编辑器侧行为与预览→编辑完全一致（独占预览模式走 D5 pending）。双屏模式下跳转后焦点落在编辑器 |
| Download SVG | Blob + `URL.createObjectURL`，文件名 `diagram.svg`（同名冲突时由浏览器自动加后缀），完成后 toast `SVG exported!`（success）。**下载失败**（序列化/权限）→ 按钮保持可用 + toast `Failed to export SVG`（error），浮层不关闭 |
| 焦点 | Tab 在浮层内循环（面板内 3 个按钮级元素：✕ / `Go to source` / `Download SVG`，无需完整 focus trap 库）；关闭后焦点回到触发它的图 |
| 滚动锁定 | `html/body/#root` 已是 `overflow:hidden`，无需额外处理 |

> 关闭方式共三种：ESC、点击遮罩、✕。**不设独立的 `Close` 文字按钮**（避免与 ✕ 重复、操作区三个按钮过重）。

### 3.4 空态 / 异常态

- 图区无内容（SVG 被 sanitize 剥空）→ 显示占位文字 `Diagram could not be rendered.`，`Download SVG` 置灰（`disabled`）；`Go to source` **保持可用**（跳转到源码是此时的唯一出路）。
- 多个图同时存在时，**每次只开一个浮层**，内容与触发块一一对应。

### 3.5 响应式 / 溢出

- 面板 `width: min(92vw, 1100px)`、`max-height: 88vh`；窗口小于 480px 时 `padding: 12px`，操作区 `flex-wrap: wrap`。
- 超大图：图区内部滚动（横向 + 纵向），面板不超出视口。

## §4 代码块复制按钮（C3）

### 4.1 视觉形态

所有预览代码块（含 Source 态 mermaid 块）右上角一个浮动小按钮，**默认隐藏，hover / 聚焦时出现**；复制成功切换为 ✓ + `Copied`。

### 4.2 尺寸 / 间距 / 圆角 / 字号

| 元素 | 规格 |
|---|---|
| 包裹层 `.preview-codeblock` | `position: relative; margin: 0 0 1em;`（原 `pre` 的 `margin` 上移到包裹层，`pre` 改 `margin: 0`） |
| `pre`（在包裹层内） | **顶部内边距 16px → 32px**（给按钮留出净空，避免第一行代码被压住）；其余沿用现有 `.preview-pane pre` 样式 |
| 按钮 `.preview-copy-btn` | `position: absolute; top: 6px; right: 6px; height: 24px; padding: 0 8px; border: 1px solid var(--mf-border); border-radius: 4px; background: var(--mf-bg-primary); color: var(--mf-text-secondary); font-size: 11.5px; opacity: 0; visibility: hidden; transition: opacity .12s ease, background-color .15s ease;` |
| 显示条件 | `.preview-codeblock:hover .preview-copy-btn`、`:focus-within`、`:focus-visible`、`.is-copied` → `opacity: 1; visibility: visible;` |

### 4.3 交互态

| 态 | 文案 | 视觉 |
|---|---|---|
| default | `Copy` | 见 §4.2 |
| hover | `Copy` | 背景 `--mf-bg-hover`，字色 `--mf-text-primary` |
| active（按下） | `Copy` | 背景 `--mf-bg-active` |
| 成功 `.is-copied` | `✓ Copied` | 字色 + 边框 `--mf-success`；**保持可见 1.5s** 后回到隐藏态 |
| 失败 `.is-failed` | `Copy failed` | 字色 + 边框 `--mf-error`；保持可见 1.5s |
| focus-visible | — | §0.2 焦点环；**即使未 hover 也可见** |

### 4.4 空态 / 异常态

- 空代码块 → 按钮照常出现，点击复制空串（不报错，反馈 `Copied`）。
- 剪贴板 API 不可用（非安全上下文）→ 走 `document.execCommand('copy')` 兜底；都不行 → `Copy failed` 态 + **不弹 toast**（避免噪音，按钮上已有反馈）。
- 复制内容 = 纯代码文本，**不含**围栏、不含行号、不含首尾多余空行。

### 4.5 响应式 / 溢出

- 按钮固定在包裹层右上角，不随 `pre` 的横向滚动移动（这是必须包裹一层、不能把按钮塞进 `pre` 的原因）。
- 窄屏下按钮不换行、不缩放。

## §5 预览块级稀疏行号（R4）

### 5.1 视觉形态

设置开时，**每个带源行锚点的块元素**在其左侧 gutter 显示该块的**起始源行号**；稀疏（不是每行都有），与编辑器行号**同一套编号**（1-based，见 5.6）。

### 5.2 尺寸 / 间距 / 圆角 / 字号

| 项 | 规格 |
|---|---|
| 开启标记 | `.preview-pane` 上加 class `show-line-numbers` |
| gutter 预留 | `.preview-pane.show-line-numbers .preview-content { padding-left: var(--preview-gutter-width, 3.6em); }`（**新增尺寸变量，非颜色变量**） |
| 数字 `.preview-pane.show-line-numbers [data-source-line]::before` | `content: attr(data-line-no); position: absolute; right: 100%; top: 0; padding-right: 8px;` |
| 字型 | `'SF Mono', 'Fira Code', Consolas, monospace`（与编辑器 gutter 一致） |
| 字号 | `0.8em`（随 `--preview-font-size`） |
| 行高 | `inherit`（随 `--editor-line-height`，与块首行对齐） |
| 字色 | `--mf-text-muted` |
| 其他 | `font-variant-numeric: tabular-nums; white-space: nowrap; user-select: none; pointer-events: none;` |

参考实现要点（伪元素定位，非源码）：

```css
.preview-pane.show-line-numbers [data-source-line] { position: relative; }
.preview-pane.show-line-numbers [data-source-line]::before { /* 见上表 */ }
/* 嵌套块只显示最外层，避免列表里每个 li 都刷一个号 */
.preview-pane.show-line-numbers [data-source-line] [data-source-line]::before { content: none; }
```

### 5.3 与 sync 高亮不冲突（结构性保证）

- 数字画在元素**盒子之外**（`right: 100%`），`.sync-highlight` 闪烁只改元素自身的 `background-color`，**不会盖到 gutter**，数字也不会跟着闪。
- 数字色恒为 `--mf-text-muted`，不参与任何闪烁动画。
- ⚠️ **和 R3 的协作约束**：R3「B 增强档」要打**行级 span 锚点**，那个属性**必须换名**（建议 `data-line-row`），**不能复用 `data-source-line`**，否则行号规则会匹配到几千个 span，满屏数字且性能崩。这一条需要架构师在实现 R3 时同步遵守。

### 5.4 空态 / 异常态

- 无 `data-source-line` 的元素 → 无数字（不补 0、不占位）。
- 表格：行号画在**横向滚动包裹层**（`.preview-table-wrap`）上，不画在 `<table>` 上——否则数字落在 `overflow-x:auto` 容器的左侧溢出区，被裁掉且无法滚到（见 §7 实现方式）。
- 导出 / 打印：**不显示**（见 §9）。

### 5.5 响应式 / 溢出

- gutter 宽度按 `3.6em` 预留，随字号伸缩；数字最长按 6 位（约 3.6em）估，配合 `.preview-pane` 现有 `padding-left: 40px` 兜底，**任何情况下都不出现横向滚动条**。
- 窄预览区（< 420px）：gutter 仍完整显示，正文相应变窄（不做隐藏降级，否则行号就失去意义）。

### 5.6 编号基准（重要）

`md-worker` 写的 `data-source-line` 是 markdown-it 的 `map[0]`，**0-based**；编辑器 `editor:goto-line` 也是按 0-based 处理的（`EditorPane.tsx:861` 用 `doc.line(line + 1)`）。
**但用户看到的编辑器行号是 1-based**，所以预览 gutter **显示 `data-source-line + 1`**。
实现约定：后处理时额外写 `data-line-no = Number(data-source-line) + 1` 给 CSS 用；**`data-source-line` 本身保持 0-based 不变**，以免破坏 R2/R3 的既有算法。

## §7 宽表格横向滚动容器（C4）

### 7.1 视觉形态

每个 `<table>` 外包一层滚动容器，表格自身横向滚动，**预览区不出现页面级横向滚动条**。

### 7.2 尺寸 / 间距 / 圆角 / 字号

| 元素 | 规格 |
|---|---|
| 包裹层 `.preview-table-wrap` | `margin: 0 0 1em; max-width: 100%; overflow-x: auto; overscroll-behavior-x: contain;` |
| 表 `table` | `width: auto; min-width: 100%; margin: 0;`（窄表仍撑满，宽表按内容展开）；其余沿用 `.preview-pane table/th/td` |
| 滚动条 | 不单独设样式，继承全局 `::-webkit-scrollbar`（8px）+ `--mf-scrollbar-thumb`，**自动跟随明暗主题** |
| 行号 | `data-source-line` / `data-line-no` 从 `<table>` **搬到包裹层**上，行号画在包裹层外侧，不被 `overflow-x` 裁掉 |

参考实现要点：

```css
.preview-table-wrap { overflow-x: auto; }
.preview-table-wrap > table { width: auto; min-width: 100%; margin: 0; }
```

### 7.3 交互态

- 无 hover / active 态变化（纯容器）。
- 鼠标横向滚轮 / 触控板横滑可用；键盘用户可用 Tab 进入表内链接后由浏览器自动滚动。
- 滚动条 thumb hover 用全局规则（`--mf-text-muted`）。

### 7.4 空态 / 异常态

- 列数 ≤ 容器宽度时：**滚动条不出现**（`overflow-x: auto` 而非 `scroll`），外观与现状一致。
- 表格在 `<li>` / `<blockquote>` 内嵌套：照常包裹，跟随父级宽度。

### 7.5 响应式 / 溢出

- 打印 / 导出 PDF：`@media print { .preview-table-wrap { overflow-x: visible; } }`，避免 PDF 里表格被裁切。
- 预览区宽度变化时重算，无需 JS 监听（纯 CSS）。

## §12 验收口径对照（QA 照这个点测）

> 全部**人工真机点测**，两端（桌面 / 插件）各一轮；不做 E2E、不用截图脚本代替（项目质量约定）。

### A6 — 11 种保留图类型各一例
1. 依次插入 flowchart / sequenceDiagram / classDiagram / stateDiagram / erDiagram / gantt / pie / journey / timeline / gitGraph / mindmap 各一例。
2. **每一例都渲染出图**（不是源码块，不是空白）。
3. 图的右边缘**在预览区内容宽度之内**，预览区底部/右侧**没有新增横向滚动条**。
4. 图内文字不与框线重叠、节点不互相压字（对照同类工具「乱七八糟」的错乱样例）。
5. 切到暗色主题后重看：线条/文字都变成暗色主题的对比关系，**没有残留亮色底或黑字糊在深底上**。
6. 首次渲染从敲完到出图 ≤ 1s（主观无等待感）。

### A9 — 单块切 Diagram ⟷ Source
1. 文档里放 3 个 mermaid 块。点第 2 块的 `Source` → **只有第 2 块变成代码**，第 1、3 块仍是图。
2. 再点第 2 块 `Diagram` → 恢复成图。
3. 上下滚动、切主题、编辑别处内容后回来：第 2 块的切换态**保持用户上次的选择**（逐块独立，互不干扰）。
4. Source 态的代码块样式与文档里普通代码块**一致**（背景、圆角、字号、hljs 配色无差别）。

### A11 — 点击图 → 放大 / 下载 SVG（含 Q1 裁决后的点击归属）

## §13.2 给工程师的实现约束（三条，务必照做）

> 这三条原本只在沟通消息里出现过；07 是工程师的正式输入之一，故在此固化。

### 约束 1 — R3 行级锚点属性**必须换名**，不得复用 `data-source-line`

| 项 | 内容 |
|---|---|
| 原名 | `data-source-line`（`md-worker.ts:98-111` 的 `source_line_attr` 规则给块级开标签打的 0-based 行号） |
| 现状用途 | ① R2 预览→编辑定位；② R3 编辑→预览定位；③ **R4 行号 gutter 的 CSS 选择器**（`.preview-pane.show-line-numbers [data-source-line]::before`） |
| 新属性 | R3「B 增强档」要打的**行级 span 锚点**请改用**新名字**，建议 `data-line-row`（或其他不叫 `data-source-line` 的名字） |
| 为什么 | 行号规则是纯 CSS 属性选择器，**不看标签类型**。行级 span 若也带 `data-source-line`，一个 5000 行的文档会凭空多出 5000 个 gutter 数字：① 满屏数字、视觉崩坏；② 每个 span 都要 `position: relative` + 伪元素，布局与性能一起崩（直接冲击 20MB 文档红线与「输入延迟 < 30ms」） |
| 附加 | 同时建议给行级 span 加 `:not()` 兜底：行号选择器写成 `[data-source-line]:not(span)`，双保险 |

### 约束 2 — 行号**显示 1-based**，`data-source-line` 本身保持 0-based 不变

| 项 | 内容 |
|---|---|
| 原名 / 原值 | `data-source-line` = markdown-it `token.map[0]`，**0 起始**；`EditorPane.tsx:861` 的 `editor:goto-line` 也是按 0-based 消费（`doc.line(line + 1)`） |
| 改成什么 | **不要改 `data-source-line` 的值**。额外由预览后处理写一个**新属性** `data-line-no = Number(data-source-line) + 1`，CSS 用 `content: attr(data-line-no)` |
| 为什么 | 用户看到的编辑器 gutter 是 **1-based**。若预览 gutter 直接显示 0-based，第一行会显示 `0`，与编辑器差 1，是肉眼可见的 bug（QA 的 A12 第 2 条就是拿两者对拍）。改 `data-source-line` 本身则会破坏 R2/R3 既有算法（它们按 0-based 比较与跳转），风险远大于加一个属性 |

### 约束 3 — 表格行号画在**滚动包裹层**上，不画在 `<table>` 上

| 项 | 内容 |
|---|---|
| 原名 / 原位置 | `data-source-line`（+ `data-line-no`）当前由 worker 打在 `<table>` 上 |
| 改成什么 | C4 引入 `.preview-table-wrap`（`overflow-x: auto`）后，把这两个属性**搬到包裹层**（或让包裹层继承一份），行号伪元素随之画在包裹层左侧 |
| 为什么 | 行号伪元素用 `position: absolute; right: 100%` 画在元素盒子**左外侧**。若宿主是 `<table>`，而 table 位于一个 `overflow-x: auto` 的容器内，这段数字就落在容器的**左侧溢出区**——横向滚动条**滚不到左边**（LTR 下左溢出不可达），数字会被永久裁掉。画在包裹层外侧则落在预览区正常的左内边距里，随纵向滚动正常显示 |
