## 🔧 两种运行模式（必须双跑）

| 模式 | 触发方式 | 说明 |
|------|----------|------|
| ① **`file://` 内嵌 iframe（inline）** | 浏览器直接打开本地 `.md` 文件，扩展 content script 注入全屏 iframe | `isIframe=true`；自动保存走 postMessage 桥接父页面直写，有 15s 桥接超时 |
| ② **独立 `editor.html` 标签页** | 点击扩展图标 / `Cmd+Shift+M` / New·Open 开新标签 | `isIframe=false`；自动保存走 FSAA 直接写盘，无桥接无超时 |

**两种模式共享同一份设置（`chrome.storage.local`）**——在独立标签改的设置，inline 模式下次打开即生效，需交叉验证一次。

## 🧭 通用前置步骤（每次点测前）

1. 加载本轮构建产物 `dist-extension/`（开发者模式 / 解压加载）。
2. 进入 ① inline 模式：浏览器新标签页打开一个本地 `.md` 文件。
3. 进入 ② 独立标签模式：点击扩展图标或按 `Cmd+Shift+M` 打开编辑器。
4. 打开文档默认落 **预览（preview）** 视图；涉及双屏的用例需先**手动切到 Split** 才可见互换效果。

## 一、设置弹窗 Tabs 重构（功能 3）

> 背景：设置弹窗由单页改为 4 个 Tab（Editor / Preview / Behavior / Auto-Save），弹窗宽度 480→520px，支持方向键切换与无障碍 `role`，Reset 覆盖全部 Tab。

**A1 · 4 个 Tab 切换、内容不串、无滚动条**
- `[独立标签]` 点击扩展图标打开编辑器 → 点右上角设置（齿轮）打开弹窗 → 依次点击 Editor / Preview / Behavior / Auto-Save 四个 Tab → 每个 Tab 内容正确显示、互不串台、弹窗内无多余滚动条。
- `[inline]` 浏览器打开本地 `.md`（inline 模式）→ 同样打开设置弹窗 → 依次切 4 个 Tab → 同上预期（内容不串、无多余滚动条）。

**A10 · 设置持久化（关标签页重开保留 + 跨模式共享）**
- `[独立标签]` 在独立标签页打开设置，修改若干项（如字号、自动保存间隔）→ 关闭标签页 → 重新从扩展图标打开编辑器 → 上述修改仍然保留。
- `[inline]` 在 inline 模式打开设置，修改若干项 → 关闭该标签页 → 浏览器重新打开同一本地 `.md`（inline）→ 修改仍然保留。
- `[独立标签→inline]` 跨模式共享验证：在独立标签改完设置后，浏览器打开一个本地 `.md`（inline 模式）打开设置弹窗 → 显示的是独立标签改过的同一份设置，无需重改。

**A11 · Reset Defaults 覆盖 4 个 Tab**
- `[独立标签]` 在 4 个 Tab 中改乱若干设置 → 点 Reset Defaults → 4 个 Tab 全部回到默认值（Editor / Preview / Behavior / Auto-Save 均复位）。
- `[inline]` 同上操作 → 4 个 Tab 全部回到默认值。

**A12 · 老用户升级（旧配置无新字段不崩）**
- `[独立标签]` 使用一台此前安装过旧版插件、含旧 `mdnote-settings`（无 `splitLayout` / `autoSaveInterval` / `previewFontSize` 字段）的浏览器 → 直接加载本轮插件 → 打开应用无崩溃、无报错，新字段均取默认值（编辑器在左、自动保存默认开启、预览字号默认）。
- `[inline]` 同上旧配置环境 → 浏览器打开本地 `.md`（inline）→ 应用正常启动、无报错，新字段取默认。

## 二、预览字体跟随（Bug 5 真修点）

> 背景：PRD 原诊断「全局不跟随」与代码不符，真实根因是代码块/表格硬编码 `13.5px` 不随设置缩放；本轮改为相对单位，并新增预览字号（及预览字体族）独立可配。

**A2 · Editor 字号联动预览正文/标题**
- `[独立标签]` 设置 → Editor Tab 拖动 Font Size → 编辑器文字即时变化，且预览区正文与标题同步变化（预览字形默认跟随编辑器字号）。
- `[inline]` 同上 → 编辑器与预览正文/标题同步变化。

**A3 · Preview 字号独立（仅预览变，编辑器不变）**
- `[独立标签]` 设置 → Preview Tab 拖动 Preview Font Size → 仅预览区字体大小变化，编辑器字号不受影响。
- `[inline]` 同上 → 仅预览区变化，编辑器不变。

**A4 · 代码块 / 表格字号跟随预览字号（Bug 5 真修点）**
- `[独立标签]` 打开一篇含代码块与表格的 `.md` → 设置 Preview Font Size 调大 / 调小 → 预览区内的代码块与表格字号随之缩放（不再恒为固定值）。
- `[inline]` 同上文档与操作 → 代码块与表格字号跟随预览字号变化。

## 三、双屏左右互换（功能 1 · splitLayout）

> 背景：Behavior Tab 新增 Split Layout 选项（Editor Left / Editor Right），以 class 切换 `flex-direction: row-reverse`；分隔线随编辑器位置换边（修复 R6）。

**A5 · 互换布局，分隔线居中**
- `[独立标签]` 打开文档（默认 preview）→ 手动切到 Split 视图 → 设置 → Behavior Tab → Split Layout 选「Editor Right」→ 编辑器移到右侧、预览在左、**中间两栏之间有分隔线**（分隔线不在窗口最右缘）。
- `[inline]` 浏览器打开本地 `.md` → 先手动切到 Split → 同样将 Split Layout 设为 Editor Right → 编辑器在右、预览在左、分隔线位于两栏之间。

**A6 · 互换后 TOC 跳转与同步滚动仍正常**
- `[独立标签]` 互换为 Editor Right 后 → 点击预览区 TOC 标题 → 编辑器跳转到对应源码行；在编辑器滚动 / 输入 → 预览同步滚动正常、不串位。
- `[inline]` 同上互换后 → 点击 TOC 跳转、编辑↔预览同步滚动均正常。

## 四、预览防闪烁（Bug 6 真修点）

> 背景：闪烁真因是 `isPreviewLoading` 早返回整体替换 DOM（每 150ms 闪一次「Rendering…」），非 `dangerouslySetInnerHTML`。本轮去掉早返回，容器恒定 + 覆盖层，用 `useLayoutEffect` 手动 `innerHTML` 并在绘制前恢复滚动位置。

**A7 · Split 连续打字无闪白、滚动不跳**
- `[独立标签]` 切到 Split → 在编辑器连续快速打字（含中英文、长段落）→ 预览区无「Rendering…」闪白、滚动位置不跳动、不回顶。
- `[inline]` 同上连续快速打字 → 预览区无闪白、滚动位置稳定不跳。

## 五、自动保存频率可配 + 关闭（功能 2）

> 背景：以 `settings.autoSaveInterval`（毫秒，0=关闭）为唯一真源，取消 `autoSaveEnabled` 独立状态源；关闭时连内容变化后的 3s 快捷保存一并停止（尊重用户意图）。StatusBar 文案随设置变化（`Auto-save (5s)` / `(OFF)`），勾选框与设置双向联动。
> **inline 模式为重点**：静默保存走 postMessage 桥接，未授权 / 已授权两种场景均需验证，且不弹遮罩、不刷 error、不重复写。

**A8 · 自动保存间隔生效与关闭**
- `[独立标签]` 设置 → Auto-Save Tab 选 5s → 编辑内容后观察约 5s → 文件落盘（重新打开内容在）。
- `[独立标签]` 同一 Tab 选「不自动保存」(OFF) → 继续编辑 → 不再自动落盘，且内容变化后的 3s 快捷保存也停止（不后台偷偷写盘）。
- `[inline]` 选 5s（已授权场景）→ 编辑后约 5s 静默落盘、无重复写（请求不叠加）。
- `[inline]` 选 5s 但未授权（首次 / 无写权限）→ 不弹授权遮罩、不刷 error，按设计处理（不落盘而非崩溃）。

**A9 · StatusBar 文案与勾选框联动**
- `[独立标签]` 设 5s → StatusBar 显示「Auto-save (5s)」、勾选框为勾选；设 OFF → 显示「Auto-save (OFF)」、勾选框取消；手动勾选/取消勾选框 → 设置中的 autoSaveInterval 同步变化（开→恢复上次非零间隔，关→0）。
- `[inline]` 同上 → StatusBar 文案与勾选框联动一致。
