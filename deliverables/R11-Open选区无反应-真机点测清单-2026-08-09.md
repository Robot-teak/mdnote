## 1. 主测：当前页**有内容** + 已勾选「允许访问文件网址」
1. 浏览器打开一个 `.md` 文件（内联编辑器显示其内容 = 当前页有内容）。
2. 在编辑器里点工具栏 **📂 Open**。
3. 原生文件框弹出 → 选**另一个** `.md` 文件 → 打开。
4. **预期（R9 诉求）**：
   - 弹出一个**新的 file:// 目录标签**（显示该 `.md` 所在文件夹的列表页）；
   - **当前页（原文档）完全不动**，未保存的修改保留。
   - 在目录列表里点一下刚选的 `.md`，那个新标签即变成它的内联编辑器。
5. **PASS 判据**：看到新 file:// 目录标签 + 当前页内容不变。

## 2. 对照：当前页**空文档**
1. 在编辑器里点 **📄 New**（或当前页内容为空）。
2. 点 **📂 Open** → 选一个 `.md` → 打开。
3. **预期**：选中文件内容**直接渲染进当前编辑器**（不新开标签）。
4. **PASS 判据**：当前页出现选中文件的内容。

## 3. 若 T1 仍异常 —— 开控制台抓日志
1. 在 file:// 文档页按 `F12` / `Cmd+Opt+I` 打开 DevTools，**Console** 面板。
2. 重复 T1 的 Open 操作。
3. 把 Console 里所有 `[MDnote][Open]` 开头的行**贴回来**（按顺序），据此定位断点。
   关键日志点：
   - `iframe 发出 mdnote:open-file-request, docEmpty = …`
   - `content script 收到 open-file-request, docEmpty = …`
   - `showOpenFilePicker 已返回句柄: <文件名>`
   - `非空文档 → 尝试在新标签打开目录: file://…`
   - `已在新标签打开目录列表，当前页保持不变` ← 成功会打印这条
   - `window.open 被拦截，退回 background 代开` ← 若 window.open 被挡，会走兜底
   - `finishOpen → 回传 mdnote:file-picked: …`
   - `iframe 收到 file-picked（含内容）/（openedInNewTab）…`
